# Локальная реконструкция предмета

Подключение GPU-сервиса отложено по решению пользователя. Наличие этого адаптера не означает, что нейросеть была установлена или проверена на текущем компьютере.

Основа: официальный [Stable Fast 3D](https://github.com/Stability-AI/stable-fast-3d). Установите его в отдельном окружении по инструкции upstream, включая поддерживаемый PyTorch/CUDA и доступ к весам. Лицензия модели и требования зависят от upstream; проверяйте их при установке.

Из папки RoomPlan, используя Python окружения SF3D:

```powershell
python -m roomplan.sf3d_service --repo C:/path/to/stable-fast-3d --port 8877
```

В другом терминале перед запуском RoomPlan:

```powershell
$env:ROOMPLAN_RECONSTRUCTION_URL='http://127.0.0.1:8877/reconstruct'
python server.py --port 8765
```

Адаптер вызывает настоящий upstream `run.py`, читает произведённый `mesh.glb` и возвращает его приложению. При ошибке нет подмены процедурным объектом. Используется первая фотография, остальные сохраняются в проекте. Масштаб single-image результата неизвестен; реальные габариты задаёт пользователь.

## Контракт исследовательского сервиса

POST JSON:

```json
{"files":[{"name":"chair.png","mime":"image/png","data":"BASE64_BYTES"}],"name":"Кресло"}
```

Ответ:

```json
{"asset":{"name":"mesh.glb","mime":"model/gltf-binary","data":"BASE64_GLB"},"method":"Stable Fast 3D"}
```

RoomPlan принимает только loopback HTTP endpoint. GPU на другом компьютере можно подключить через локальное SSH-перенаправление. Загруженные фото по умолчанию никуда не отправляются. Обработчик CPU-планов и демонстрационные режимы видео/фото независимы от GPU.

Для нового multi-view метода замените inference внутри локального сервиса, принимая весь `files`; обновите имя метода и ограничения. Для реконструкции квартиры точки подключения находятся в `roomplan/reconstruction.py`: результат должен соблюдать метрическую модель из SPEC.md и сохранять provenance и исходные файлы.
