# Third-party dependencies and reference material

- Three.js 0.180.0, MIT, https://github.com/mrdoob/three.js . Vendored unmodified under web/vendor/three. License included in that directory. Obtained from https://registry.npmjs.org/three/-/three-0.180.0.tgz .
- three-gpu-pathtracer 0.0.23, MIT, https://github.com/gkjohnson/three-gpu-pathtracer . Optional local WebGL still renderer; source and license vendored under web/vendor/three-gpu-pathtracer from the official npm package.
- three-mesh-bvh 0.9.1, MIT, https://github.com/gkjohnson/three-mesh-bvh . Local acceleration structures; source and license vendored under web/vendor/three-mesh-bvh from the official npm package.
- glslSmartDeNoise shader, BSD-2-Clause, included by three-gpu-pathtracer; license preserved in web/vendor/three-gpu-pathtracer/LICENSE-glslSmartDeNoise.
- Pillow and NumPy: Python imaging and array processing. Install with requirements.txt.
- Floorplanner gallery images: external quality references only; copyright remains with Floorplanner. They are not furniture/application assets. See docs/quality-bar.md for fixed URLs and comparison conditions.
- Procedural furniture and example apartment in this repository are original prototype assets; geometric representations are not branded product models.

Photo uploads and external reconstruction: no image is sent externally by the plan/video/photos endpoints. Object inference provider behavior is separately documented and must be visible before sending.
